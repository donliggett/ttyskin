# Fonts

`Uni2-Fixed16.psf.gz` is the 8×16 Uni2 Fixed console font from the console-setup package (Anton Zinoviev). ttyskin's tests use it, and `ttyskin.html` embeds a copy as the page's default font.

console-setup's copyright statement says: "All console fonts are public domain by nature." The font is not covered by ttyskin's MIT license.
